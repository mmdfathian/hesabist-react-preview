تبدیل تن به کیلوگرم

برای تبدیل تن به کیلوگرم از فرمول زیر استفاده کنید: ۱ تن = ۱٬۰۰۰ کیلوگرم — یعنی هر تن برابر است با ۱٬۰۰۰ کیلوگرم. جدول زیر مقدارهای پرکاربرد را نشان می‌دهد؛ برای هر مقدار دیگری می‌توانید از ابزار تبدیل واحد استفاده کنید.
