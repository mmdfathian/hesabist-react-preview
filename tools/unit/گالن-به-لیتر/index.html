تبدیل گالن به لیتر

برای تبدیل گالن به لیتر از فرمول زیر استفاده کنید: ۱ گالن = ۳٫۷۸۵۴۱ لیتر — یعنی هر گالن برابر است با ۳٫۷۸۵۴۱ لیتر. جدول زیر مقدارهای پرکاربرد را نشان می‌دهد؛ برای هر مقدار دیگری می‌توانید از ابزار تبدیل واحد استفاده کنید.
