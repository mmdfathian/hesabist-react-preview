تبدیل لیتر به متر مکعب

برای تبدیل لیتر به متر مکعب از فرمول زیر استفاده کنید: ۱ لیتر = ۰٫۰۰۱ متر مکعب — یعنی هر لیتر برابر است با ۰٫۰۰۱ متر مکعب. جدول زیر مقدارهای پرکاربرد را نشان می‌دهد؛ برای هر مقدار دیگری می‌توانید از ابزار تبدیل واحد استفاده کنید.
