تبدیل لیتر به گالن

برای تبدیل لیتر به گالن از فرمول زیر استفاده کنید: ۱ لیتر = ۰٫۲۶۴۱۷۲ گالن — یعنی هر لیتر برابر است با ۰٫۲۶۴۱۷۲ گالن. جدول زیر مقدارهای پرکاربرد را نشان می‌دهد؛ برای هر مقدار دیگری می‌توانید از ابزار تبدیل واحد استفاده کنید.
