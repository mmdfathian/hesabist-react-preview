تبدیل متر به فوت

برای تبدیل متر به فوت از فرمول زیر استفاده کنید: ۱ متر = ۳٫۲۸۰۸۴ فوت — یعنی هر متر برابر است با ۳٫۲۸۰۸۴ فوت. جدول زیر مقدارهای پرکاربرد را نشان می‌دهد؛ برای هر مقدار دیگری می‌توانید از ابزار تبدیل واحد استفاده کنید.
